# Audit 001: `/kiblat` (UI Anti-Slop, Design Craft, A11y & Verifikasi Fitur)

- **Tanggal:** 2026-11-25
- **Mode Antislop:** `after`
- **Target:** `src/app/(dashboard)/kiblat/` (`page.tsx`, `KiblatClient.tsx`, `KiblatAstrolabe3D.tsx`, `QiblaMap.tsx`, `kiblat.css`), dependensi kalkulasi (`src/lib/prayerTimes.ts`, `src/lib/kemenagPrayerTimes.ts`), dan token layout global (`src/app/globals.css`, `next.config.ts`)
- **Design Read:** Reading this as: *Astronomical & Worship Utility Dashboard* for *alumni & muslim users on desktop & mobile*, in a *Luxury Horology Instrument (obsidian brass, marble & emerald alignment)* style, dial **ENERGY 2 / RHYTHM 2 / MOTION 1**.

## Ringkasan Audit Multi-Skill

- **Impeccable Detector (`impeccable detect --json`):** `0` temuan statis dari CLI detector.
- **Kesesuaian Framing 3D Terbaru:** Lingkaran penuh bezel kuningan dan cincin kursi atas pada stage WebGL 3D tampil utuh pada viewport desktop (`recording_2.mp4`, `recording_11.mp4`) tanpa terpotong tepi bawah canvas.
- **Ringkasan Skor Kesehatan Teknis (`impeccable audit`):**
  - Accessibility: **1/4** (kegagalan kontras Mode Terang, `outline: none`, label/ARIA tablist & slider hilang, indikator status hanya berbasis warna)
  - Performance: **2/4** (`useEffect` jadwal Kemenag dipicu ulang setiap 1 detik oleh state `now`, `transition: all` berulang, animasi loop tak terbatas tanpa `prefers-reduced-motion`)
  - Theming: **1/4** (variabel `--font-manrope`/`--font-inter` di `:root` `globals.css` mengalami self-reference invalid sehingga UI jatuh ke `Times New Roman`; beberapa kontrol di Mode Terang tetap memakai gaya gelap/kontras di bawah 3:1)
  - Responsive Design: **2/4** (9 kelas tombol/kontrol di mobile di bawah ukuran sentuh 44x44px; dial 2D memakai radius translate tetap `-145px`)
  - Implementation Integrity: **2/4** (beberapa bug kalkulasi koordinat N/S, kuadran U-B, zona waktu banner sholat, status sensor palsu di desktop, hydration error #418, serta pelanggaran CSP di produksi)
  - **Total:** **8/20 (Poor, perlu perbaikan terarah sebelum rilis)**

## Tabel Evaluasi Gerak & Interaksi (`emil-design-eng`)

| Before | After | Why |
| --- | --- | --- |
| `transition: all 0.25s ease` (`kiblat.css:63,198,599,733,1230,1541,1657`) | `transition: transform 160ms cubic-bezier(0.23, 1, 0.32, 1), background-color 180ms ease, border-color 180ms ease` | Menghindari overhead properti tak disengaja dan memberi respons `ease-out` instan |
| Tidak ada `:active` press state pada tombol (`btn-gps`, `btn-auto-align`, `astrolabe-seg-btn`) | `transform: scale(0.97)` di dalam `:active` (berlaku untuk pointer presisi & sentuh aman) | Konfirmasi taktil langsung saat tombol ditekan |
| `.prayer-card:hover { transform: translateY(-3px) }` di semua perangkat | `@media (hover: hover) and (pointer: fine)` + step permukaan tenang | Mencegah efek hover tersangkut pada layar sentuh HP |
| Animasi infinite `pulseKaaba`, `pulseTurn`, `statusPulse`, `pulseRing` jalan di semua preferensi | Matikan atau ganti transisi warna statis di `@media (prefers-reduced-motion: reduce)` | Menghormati preferensi aksesibilitas gerak pengguna |
| `hover` & focus tanpa `outline-visible` yang jelas | `:focus-visible { outline: 2px solid var(--gold-main); outline-offset: 2px; }` | Aksesibilitas keyboard konsisten pada mode Gelap dan Terang |

## Matriks Verifikasi Fitur Aktual (`/kiblat` di Chrome Live + Inspeksi Kode)

- **3D Astrolabe (`Perspektif`, `Ka'bah`, `Atas`, `2D`, `3D Ka'bah`):** **PASS** (tab kamera berpindah aktif bersih, `2D` & `3D` berganti tanpa error, bezel penuh tampak utuh pada canvas desktop). Drag pointer kanan/kiri pada `<canvas>` belum teruji oleh otomasi a11y karena node WebGL tidak punya ARIA label/kontrol keyboard.
- **Switcher Mode Perangkat (`Desktop` / `Mobile`):** **PARTIAL FAIL** (panel berganti, tetapi di PC tanpa magnetometer status langsung mengklaim `"Sensor Kompas Ponsel Aktif"`, dan tombol aktivasi hilang saat bolak-balik).
- **Pemilih Kota & Kalkulasi Kiblat (`Ponorogo`, `Jakarta`, `Makassar`, `Mekkah`):** **PARTIAL FAIL** (bearing & jarak terbarui akurat, tetapi koordinat `Mekkah` salah tampil `° S`, `Sudut dari Barat` rusak di kuadran non-Barat Laut, label `"WIB"` dipaku di semua kota, dan banner terkunci menyebut arah kompas saat ini di sebelah bearing tetap).
- **Deteksi GPS (`Deteksi GPS`):** **PARTIAL FAIL** (memicu izin browser, menampilkan state `Mencari...`, namun error fallback memakai `window.alert` blocking).
- **Kalibrasi Offset (`-5°`, `-1°`, `Reset`, `+1°`, `+5°`), Slider & Snap Preset (`Utara`, `Barat`, `Timur`, `Ka'bah`):** **PASS (Pointer/Keyboard panah)** (sudut dan status terkunci terbarui akurat; kontrol hanya perlu target sentuh 44px dan label ARIA).
- **Peta Garis Kiblat Satelit (`Leaflet`):** **PASS** (peta satelit & jalan berganti bersih, `Lokasi Saya (Zoom)`, `Jalur ke Makkah`, dan popup pin pengguna berfungsi tanpa error tile/konsol; terindikasi butuh kontrol ukuran target di mobile).
- **Pemutar Adzan (`Makkah`, `Madinah`, `Play`, `Pause`, `Stop`, `Doa Setelah Adzan`, `Uji Alarm 5 Detik`):** **PASS** (audio berputar mulus sampai selesai/reset, doa buka-tutup berfungsi, toast simulasi alarm muncul bersih). Catatan: fallback audio CDN dan `api.myquran.com` berisiko terblokir CSP di produksi (`next.config.ts`).
- **Mode Terang (`Siang`) vs Mode Gelap (`Malam`):** **FAIL** (komposisi terbaca, tetapi warna `#2bb97c` & `#aa771c` pada badge/tombol putih gagal WCAG AA, plus beberapa tombol kehilangan border pada latar terang).
- **Stabilitas Background Timer & Konsol Browser:** **FAIL** (`useEffect` Kemenag terpanggil tiap 1 detik karena `now`, React error #418 saat mount, `/_vercel/insights/script.js` 404 lokal, `cdn.jsdelivr.net` diblokir CSP, dan `PCFSoftShadowMap` deprecated).
